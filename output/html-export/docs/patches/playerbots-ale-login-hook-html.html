Playerbots ALE Login Hook Patch

Overview

This patch makes mod-playerbots trigger PLAYER_EVENT_ON_LOGIN for bots when they log in, ensuring Lua scripts can register periodic events and initialize bot behaviors just like real players.

Problem

Playerbots logs bots in through its own C++ code path (OnBotLoginInternal), bypassing the ALE Lua hooks. This means Lua scripts that register for PLAYER_EVENT_ON_LOGIN never fire for bots, causing: - Bot behaviors never initialize (no wandering, no combat seeking) - Bots stand at spawn position doing nothing - Global timers that iterate GetPlayersInWorld() encounter uninitialized bot references

Files to Modify

1. modules/mod-playerbots/src/Bot/RandomPlayerbotMgr.cpp

Add include at top of file (after existing includes):

``cpp #include "LuaEngine.h" // ALE Lua engine for triggering login hooks 


Find OnBotLoginInternal function (around line 2519):
cpp void RandomPlayerbotMgr::OnBotLoginInternal(Player const bot) { if (_isBotLogging) { LOG_INFO("playerbots", "{}/{} Bot {} logged in", playerBots.size(), sRandomPlayerbotMgr.GetMaxAllowedBotCount(), bot->GetName().c_str());

if (playerBots.size() == sRandomPlayerbotMgr.GetMaxAllowedBotCount()) { _isBotLogging = false; } }

if (sPlayerbotAIConfig.randomBotFixedLevel) { bot->SetPlayerFlag(PLAYER_FLAGS_NO_XP_GAIN); } else { bot->RemovePlayerFlag(PLAYER_FLAGS_NO_XP_GAIN); } } 


Replace with:
cpp void RandomPlayerbotMgr::OnBotLoginInternal(Player const bot) { if (_isBotLogging) { LOG_INFO("playerbots", "{}/{} Bot {} logged in", playerBots.size(), sRandomPlayerbotMgr.GetMaxAllowedBotCount(), bot->GetName().c_str());

if (playerBots.size() == sRandomPlayerbotMgr.GetMaxAllowedBotCount()) { _isBotLogging = false; } }

if (sPlayerbotAIConfig.randomBotFixedLevel) { bot->SetPlayerFlag(PLAYER_FLAGS_NO_XP_GAIN); } else { bot->RemovePlayerFlag(PLAYER_FLAGS_NO_XP_GAIN); }

// Trigger ALE Lua login hook so Lua scripts can initialize bot behaviors // This ensures bots are treated identically to real players for Lua event handling // Issue 324: playerbots-ale-login-hook sALE->OnLogin(bot); } 


<h3>2. modules/mod-playerbots/mod-playerbots.cmake (required)</h3>


AzerothCore&#39;s module system includes {module-name}.cmake files during build.
Create this file to add mod-ale include paths so playerbots can find LuaEngine.h:
cmake

mod-playerbots.cmake

Generated by patch B002 (Issue 324)

Adds mod-ale include directories so playerbots can call ALE hooks

if (MOD_ALE_FOUND) message(STATUS " +- mod-playerbots: Adding mod-ale include paths for ALE integration") target_include_directories(modules PUBLIC ${MOD_ALE_PATH}/LuaEngine) endif() `

This uses the MOD_ALE_FOUND and MOD_ALE_PATH variables set by the parent modules/CMakeLists.txt.

Verification

After applying this patch:

1. Start worldserver 2. Let bots autologin 3. Check Server.log for: [PeriodicEvents] Registered behavior events for bot: <name> 4. Bots should begin wandering and exhibiting normal behaviors
