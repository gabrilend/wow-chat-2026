    <h1 class='fqn'>
        Class <a class="mod" href="">SpellInfo</a>
        <span class='out-of-band'>
            <span id='render-detail'>
                <a id="collapse-all" href="#">[-]</a>
                <a id="expand-all" href="#">[+]</a>
            </span>
        </span>
    </h1>

    
    <p>Represents spell metadata used for behavior, targeting, attributes, mechanics, auras, and conditions.</p>
<p>Unlike <a class="mod" href="../SpellEntry/index.html">SpellEntry</a>, this class includes helper functions and logic used to determine spell behavior in-game.
Used for checking if a spell is passive, area-targeted, profession-related, or has specific effects or auras.</p>
<p>Inherits all methods from: none</p>
