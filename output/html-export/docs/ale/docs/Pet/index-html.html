    <p>Non-<a class="mod" href="../Player/index.html">Player</a> controlled companions that fight alongside their owners.</p>
<p>Includes hunter pets, warlock demons, death knight ghouls, and other summoned creatures.
<a class="mod" href="../Pet/index.html">Pet</a>s can be temporary or permanent and have various AI behaviors and spell abilities.</p>
<p>Inherits all methods from: <a class="mod" href="../Object/index.html">Object</a>, <a class="mod" href="../WorldObject/index.html">WorldObject</a>, <a class="mod" href="../Unit/index.html">Unit</a>, [Guardian]</p>
