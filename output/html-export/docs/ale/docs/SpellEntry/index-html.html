    <h1 class='fqn'>
        Class <a class="mod" href="">SpellEntry</a>
        <span class='out-of-band'>
            <span id='render-detail'>

            </span>
        </span>
    </h1>

    
    <p>Represents spell data loaded from the DBCs, including effects, costs, attributes, and requirements.</p>
<p>Used for inspecting the properties of any spell in the game, such as mana cost, targets, or effects.</p>
<p>Inherits all methods from: none</p>
