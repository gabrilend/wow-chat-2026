    <h1 class='fqn'>
        Class <a class="mod" href="">Object</a>
        <span class='out-of-band'>
            <span id='render-detail'>
                <a id="collapse-all" href="#">[-]</a>
                <a id="expand-all" href="#">[+]</a>
            </span>
        </span>
    </h1>

    
    <p>A basic game object (either an <a class="mod" href="../Item/index.html">Item</a> or a <a class="mod" href="../WorldObject/index.html">WorldObject</a>).</p>
<p>Objects in MaNGOS/Trinity are stored an a giant block of "values".
Subclasses of Object, like <a class="mod" href="../WorldObject/index.html">WorldObject</a>, extend the block with more data specific to that subclass.
Further subclasses, like <a class="mod" href="../Player/index.html">Player</a>, extend it even further.</p>
<p>A detailed map of all the fields in this data block can be found in the UpdateFields.h file of your emulator
(it varies depending on the expansion supported).</p>
<p>The GetValue methods in this class (e.g. <a class="fn" href="../Object/GetInt32Value.html">Object:GetInt32Value</a>) provide low-level access to the data block.
Other methods, like <a class="fn" href="../Object/HasFlag.html">Object:HasFlag</a> and <a class="fn" href="../Object/GetScale.html">Object:GetScale</a>, merely wrap the GetValue methods and provide a simpler interface.</p>
<p>Inherits all methods from: none</p>
