Crear un Script

Script vs. módulo

En AzerothCore, no utilizamos los habituales scripts como en otros emuladores. En su lugar, trabajamos con módulos que son mucho más prácticos de usar. Ver Crear un módulo

Scripts

¿Todavía quieres hacer un script sencillo antes de pasar a los módulos? Lea a continuación.

Cómo aprender

Si nunca has hecho ningún script antes, puedes estudiar algunos de los scripts de los módulos, comparar, diseccionar, etc... Si encuentras algunos problemas abiertos, ¡arréglalos para mejorar tus habilidades!
