Descripción de los Campos

> Valor

El valor designa la 'Máscara de Bits' usada en varios lugares del núcleo del emulador y la Base de Datos (quest_template.RequiresClasses etc).

La fórmula para ello es: Valor = 1 << (ID - 1);
