Base de datos: World

La base de datos del mundo tiene información básicamente relacionada con criaturas, objetos, ítems, diálogos, textos e incluso se pueden hacer scripts a través de la tabla smart_scripts. También tiene traducciones, logros, eventos... Actualmente estamos trabajando para revisar estas tablas e intentar actualizar aquellas que no tienen la información correcta. Por ello, si detectas algún error en alguna de ellas, te invitamos a abrir una incidencia, aportando la información oportuna, para que podamos actualizarla. También te invitamos a crear un pull request, con las modificaciones correspondientes, para que podamos analizar el código e incorporarlo si es correcto. Actualmente, estamos trabajando en la actualización. En el próximo Actualizar base de datos-mundo
