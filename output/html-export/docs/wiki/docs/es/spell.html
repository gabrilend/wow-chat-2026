RequiresSpellFocus**

Indica que este hechizo en particular necesita un 'GO' cerca de (por ejemplo, forjas para funcionar (en caso de que sea un hechizo de profesión)). El objeto requerido para que el hechizo funcione posée el tipo 'GAMEOBJECT\_TYPE\_SPELLFOCUS' y dentro de la columna 'data0' en GameObject_template coincide justamente con el valor de 'RequiresSpellFocus'.
