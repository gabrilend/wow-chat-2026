The \spell\_dbc\ table

This table contains data regarding serverside spells which are not to be found in Client DBC files.

Spell\_Effect\_ID

- Effect\_IDs of Effect1, Effect2 and/or Effect3.

Spell\_Effect\_Apply\_Aura_ID

- EffectApplyAuraName\_IDs of EffectApplyAuraName1, EffectApplyAuraName2 and/or EffectApplyAuraName3.
