Emotes

Back-to:DBC

This DBC contains emotes which can be used by NPCs.

How to Import DBC Data onto my Database

Structure

| Column | Type | Comment | | ------ | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | | 1 | long | An ID for the emote. Must be unique. | | 2 | str | A descriptive name for the emote. | | 3 | long | Refers to an ID in this DBC file. This is the ID of the animation to play. | | 4 | flags | | | 5 | flags | | | 6 | long | | | 7 | long | Refers to an ID in this DBC file. This is the ID of the sound to play when the animation is played. |

Information on the structure this DBC file was taken from here and here. For any information on the columns without a comment, just refer to that page or here.
