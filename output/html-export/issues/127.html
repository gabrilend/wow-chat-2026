127 - Contextual Creature Spawns

Status: Open

Dependencies

- Issue 126: dungeon-room-spawn-zones (waypoint grouping concept)

Current Behavior

- Ambush system queries creature_template for level-appropriate creatures - Filters by type: type IN (2, 3, 4, 5, 6, 9, 10) - Spawns randomly from pool regardless of location - Undead might spawn in a forest, beasts in a crypt

Intended Behavior

- Pick spawn location first (random point around player) - Find nearest waypoint grouping to that point - Determine what creature types naturally belong there - Filter creature pool to matching types - Spawn contextually appropriate creature

Why Contextual Spawning?

- Immersion: undead near graveyards, beasts in forests - World feels alive and coherent - Leverages existing waypoint data from creature spawns - Players learn terrain = creature type associations - Emergent strategy: avoid certain areas for certain threats

<h2>Implementation Steps</h2>


<h3>Phase 1: Type Detection</h3>
1. Create src/lua/zone-types.lua
2. Query creature spawns per map grid cell
3. Compute dominant type per cell
4. Cache in memory at server start


<h3>Phase 2: Spawn Integration</h3>
1. Modify Ambush.randomSpawn to:
   - Pick spawn location first
   - Look up zone type for that location
   - Pass type filter to queue selection
2. Modify setupAmbushQueue to accept type parameter
3. Filter query: AND type = ? instead of type IN (...)


<h3>Phase 3: Fallback Handling</h3>
1. If no creatures match type + level, expand search
2. Try adjacent types (beast &lt;-&gt; critter, undead &lt;-&gt; humanoid)
3. Fall back to any type if nothing found
4. Log mismatches for zone data improvement


<h2>Algorithm</h2>


<pre><code class="lua"><span class="keyword">function</span> Ambush.randomSpawn(player, isRare)
    <span class="comment">-- <span class="number">1.</span> Pick spawn location</span>
    <span class="keyword">local</span> px, py = player:GetPosition()
    <span class="keyword">local</span> sx, sy = Movement.getArcSpawnPosition(px, py, MIN_DIST, MAX_DIST, player:GetO())


    <span class="comment">-- <span class="number">2.</span> Get zone type <span class="keyword">for</span> spawn location</span>
    <span class="keyword">local</span> zoneType = ZoneTypes.getTypeAt(player:GetMapId(), sx, sy)


    <span class="comment">-- <span class="number">3.</span> Get creature from queue matching type</span>
    <span class="keyword">local</span> creature = Ambush.getCreatureOfType(player, zoneType, isRare)


    <span class="comment">-- <span class="number">4.</span> Fallback <span class="keyword">if</span> no match</span>
    <span class="keyword">if</span> <span class="keyword">not</span> creature <span class="keyword">then</span>
        creature = Ambush.getAnyCreature(player, isRare)
    <span class="keyword">end</span>


    <span class="comment">-- <span class="number">5.</span> Spawn</span>
    <span class="keyword">if</span> creature <span class="keyword">then</span>
        <span class="keyword">local</span> sz = player:GetMap():GetHeight(sx, sy)
        player:SpawnCreature(creature.id, sx, sy, sz, ...)
    <span class="keyword">end</span>
<span class="keyword">end</span></code></pre>

<h2>Edge Cases</h2>


<h3>Ocean/Water</h3>
- No waypoints in deep water
- Default to beast (sea creatures) or elemental
- Or prevent spawns entirely


<h3>Zone Boundaries</h3>
- Transition areas may have mixed types
- Use weighted random based on nearby proportions
- Or pick closest dominant cell


<h3>Empty Cells</h3>
- Some grid cells have no creature data
- Inherit from nearest populated cell
- Or use map-wide default


<h3>Player Level Mismatch</h3>
- Zone has undead but no level-appropriate undead
- Fall back to any level-appropriate creature
- Log for balancing review

Type-Filtered Creature Query

-- Modified setupAmbushQueue
function Ambush.setupAmbushQueue(playerLevel, rank, creatureType)
    local typeFilter = &quot;&quot;
    if creatureType then
        typeFilter = &quot; AND type = &quot; .. creatureType
    else
        typeFilter = &quot; AND type IN (1, 2, 3, 4, 5, 6, 7, 9)&quot;
    end


    WorldDBQueryAsync(
        &quot;SELECT entry, minlevel, maxlevel, rank, type FROM creature_template &quot; ..
        &quot;WHERE minlevel &lt;= &quot; .. playerLevel ..
        &quot; AND maxlevel &gt;= &quot; .. playerLevel ..
        &quot; AND rank = &quot; .. rank ..
        &quot; AND npcflag = 0 AND lootid != 0&quot; ..
        typeFilter .. &quot;;&quot;,
        Ambush.pushToAmbushQueue
    )
end
