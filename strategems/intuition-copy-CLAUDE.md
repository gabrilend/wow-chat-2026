# Working in this copy

This is the comment-free copy of a project: the source as the machine runs
it, with no comments, no documents and no explanations. Learn it from what
it does.

Some ways in:

- Try checking the scripts directory for common actions. Their names say
  what they do; running one with no arguments or `--help` often says how
  to use it.
- Try following the compilation pipeline: find the script that builds or
  installs the project, list the sources it pulls in and in what order,
  and build your understanding of the project in that order. What goes in
  first is what everything after it stands on.
- Tests show what each part is expected to do: read a test beside the
  code it checks.
- `.intuition-copy` at the root names the commit this copy was made from.
- Where something is unclear, say what you found and what you would expect,
  rather than guessing: another copy of the project, with its comments,
  is being worked on at the same time, and the two are compared.
