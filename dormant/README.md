# Dormant

Work that was built, worked, and is parked: kept whole, with its history,
so it can be woken without being rebuilt. Nothing here is run by the
build, the tests or any hook.

Each folder has its own README saying what it is, why it sleeps, where
each file lived before, and how to wake it (move its files back with
`git mv`, so their history follows).

The owner, 2026-10-30, naming it: "Let's mark them as "dormant" and
archive them for now."

| Folder | What it is | Dormant since |
|--------|------------|---------------|
| `answer-pages/` | five architecture pages with an answer box beside every open question, a server that kept the answers, and a writer of contexts for every group of questions (issues 1102, 1102a) | 2026-10-30 |
