## Current Behavior

**The City of Heroes system, read 2026-10-15 (nothing touched).** It
lives in the game's Documents folder (`binds/`, a git repository with one
commit, 2026-08-25; earlier copies in `binds-backup-2`, `binds-backup-4`,
`backups-3`, `backups-5`, and a picture of it, `binds-operation.png`).
It is a keyboard that changes its own meaning: every bind file rebinds
the keys it names (the rest keep theirs), and its keys load other bind files
(`bindloadfilesilent`), so pressing a key moves the keyboard to a new
state. `conprint` lines draw where you are.
- **A command grammar for a mastermind's pets.** `mastermind-<kind>-start`
  binds 1-4 to the three ranks of pets (genin, jounin, oni) and all.
  Picking a rank loads that rank's file, where q, e, t, f and z are goto,
  stay, attack, follow and dismiss for that rank, and 1-3 set its stance
  (passive, defensive, aggressive). SPACE steps through the rank's pets by
  name (Air, Water, Earth, River, Cloud, Storm), each a file of its own
  binding the same keys to that one pet: a cycle from the squad to each of
  its members.
- **An aiming tree.** Folders by who (0 all, 6 your target, 7-9 one rank)
  by direction (eight compass points) by distance (close, near, far):
  5 x 8 x 3 = 120 files. In each, the pet orders go to that "who", and the
  location powers (Tar Patch, Bonfire, Black Hole, Dark Servant) land at
  that angle and distance (`pow_exec_location 270:30`). Keys 6-0 change
  who, U/O turn the aim, Y/H move it out or in, and the console draws a
  small compass of where the next power will land ("o X- o").
- **Small modal pairs.** Sitting rebinds the movement keys so that moving
  stands you up (sit-down / stand-up); hover; combat teleport on CTRL with
  each direction.
- **A tool to keep it consistent.** `elaina-script` rewrites a name across
  every file (the files grew by copy and rename).

**In this game today.** Buddies take no chat commands (B045), except the
spoken orders (617y): "attack" (all, by name, or whispered) and "go
sell". The game client can rebind keys from a macro: `/run SetBinding(
"F1", "MACRO Attack")` then `SaveBindings(GetCurrentBindingSet())`, out of
combat; a client add-on can go further, changing key meanings even in
combat through the game's secure state handlers (a state driver swapping
a set of override bindings), which is the same modal keyboard. The server
cannot rebind a client's keys by itself (no add-on channel is installed;
AIO is not used).

## Intended Behavior

A modal keyboard for commanding buddies, grown the way the City of
Heroes one was: a key picks who (all, your target's attacker, one buddy
by name, a role), another picks what (attack, follow, stay, go there,
use an ability), an aim picks where (a direction and a distance from you),
and the keys change meaning as you go, with a small display of the state.
Every key sends a spoken order the server already understands (617y), so
the keyboard and the orders grow together.
