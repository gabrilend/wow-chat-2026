## Why Promoted

written down as a sub-issue of the vanilla profile (148) because
vanilla was the first profile that wanted to use it. On reflection
it is a cross-profile system — release, beta, and any future profile
can want their own race/class availability matrix. Living as a
sub-issue of vanilla was misleading about its scope.

It now lives at **issues/716-class-combination-modifier-system.md**
in the phase-7 custom-class cluster alongside the rest of the
race/class infrastructure work.

This file remains in place as a redirect so anyone searching the
148-series finds the new home. Do not add content here; edit 716.
