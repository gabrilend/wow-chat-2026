# 156 - The Expert Profile

## Status
- Created: 2026-09-23
- Phase: 1 (Foundation — profile model)
- Priority: Low — the user says "not built yet"; basic (155) comes first.
- Blocked by: 155 (expert continues where basic ends)

## Origin

Verbatim, 2026-09-23:

> let's name it basic/expert, with this being the "basic" tier and "expert"
> being level 61-80 where you start at 60 but it's not built yet.

## Current Behavior

No profile named `expert` exists. Release caps at 20 today (despite its
earlier description as the level-80 profile), and alpha caps at 80 but runs
a different, older source tree.

## Intended Behavior

The OSR Dungeons & Dragons Expert Set to basic's Basic Set: the same game,
continued. A profile named `expert`:

- level cap **80**, new characters start at **60**;
- built the same way basic is (same source tree, modules, quality-of-life
  layer), with its own databases, realm, and Lua directory;
- Outland and Northrend as its leveling content.

## Suggested Implementation Steps

1. After 155 is complete, repeat 155a's plumbing sweep for `expert`, which
   155a's table makes mechanical.
2. Decide each row of 155b and 155c for expert. Most follow basic; the level
   rows differ (C006a's cap of 80 already exists; the start level of 60 needs
   a new C007 variant; bot band 60–80).
3. Answer the open questions, then split into sub-issues.

## Decided 2026-09-23

Verbatim:

> start fresh. But that's for a later development cycle. We'll need to copy
> the starting equipment patch and issue and modify it for level 60
> characters. I'll need to hand-pick the equipment, of course... [...]
> We'll also need the starting abilities for level 60, and maybe other
> patches as well.

So expert characters start fresh at 60, and expert needs level-60 versions
of vanilla's head-start machinery. Each is a copy-and-modify of an existing
issue and patch:

| Vanilla (level 20) | Expert (level 60) |
|---|---|
| 148h starter kit + E009, generated by `scripts/generate-vanilla-starting-equipment-sql` | a level-60 kit, hand-picked by the owner with the portrait grid (159) |
| 148h/E018 cloned kit items (required level tuned) | whatever the hand-picked kit needs; mind 148v (cloned items can render invisible) |
| 148j pretrained abilities + E010, generated by `scripts/generate-148j-pretrain-sql`, read via C022 | every trainer ability up to 60 |
| 148k auto-equip hook (`src/lua-vanilla/`) | the same hook for the level-60 kit |
| 148s bots start in the kit (B025) | bots start in the level-60 kit |
| 148q starting professions (E021) | to decide |
| 148n spawn towns (E007) | to decide: where a fresh 60 begins |

- **Riding:** a fresh 60 has neither riding skill; does the kit include
