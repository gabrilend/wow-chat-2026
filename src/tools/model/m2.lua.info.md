# m2.lua

Read the game's model files (M2 + .skin, WotLK version 264) and write
static ones (issue 506h). Layout: `docs/m2-format-wotlk.md`.

- `M2.read(m2_bytes, skin_bytes) -> model` — counts, name, bounds,
  sequences, bones (without keyframes; `keyframed` says if any), vertices
  (`positions`, `normals`, `uvs`, `weights`), textures, materials,
  lookups, and `skin` (`lookup`, `indices`, `submeshes`, `batches`,
  `bone_count_max`). Errors on the wrong magic or version, or any array
  leaving the file.
- `M2.validate(model) -> {problems}` — the drawable-model rules (indices in
  range, submesh ranges, batches naming real submeshes and materials, the
  box holding every vertex). Empty when sound.
- `M2.mesh_of(model) -> mesh` — the triangles in skin order, gltf.lua's
  mesh shape.
- `M2.write_static(mesh, name, opts) -> m2_bytes, skin_bytes` — a static
  item model shaped like the game's own (one root bone, inline "Stand",
  texture kind 2). `opts.two_sided`, `opts.duration`. Errors on more than
  65,535 vertices or indices, missing normals or texture coordinates, or an
  index out of range.
- `M2.from_gltf(gltf_mesh, opts) -> mesh` — glTF axes/metres to the game's
  (x, y, z) = glTF (z, x, y) x scale (default metres to yards); makes
  normals if missing; `opts.allow_no_uv`.
