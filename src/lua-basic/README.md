# src/lua-basic/

Lua scripts loaded by the `basic` profile (issue 155) via ALE. Linked into
`installed-files-basic/bin/lua_scripts/custom/` by E001 when the active
profile is `basic`.

Basic is the level 1–60 development baseline: stock game plus playerbots
and the quality-of-life layer. Vanilla's only script equips the level-20
starter kit, which basic deliberately does not have, so this directory is
its own rather than a link to `src/lua-vanilla/`.

Scripts:
- `outland-flights.lua` (155l) — the few flights basic keeps: the Dark
  Portal to Honor Hold or Thrallmar, Light's Hope to the Isle; route data
  in `data/outland-flight-paths.lua`.
- `titan-jewelers.lua` (155p) — the Earthen Crystal-Keeper's trade (a
  Nexus Crystal for an uncut Wrath gem) and the Un'Goro pair's wandering
  between the Crystal Pylons.
- `death-knight-souls.lua` (718) — the death knight sacrifice: a new
  death knight can't leave Acherus until it gives Sargobras one of the
  account's level-55+ characters (held on a hidden account, taken back on
  request), and it inherits that character's professions; data (profession
  spells, death knight skins and faces) in
  `data/death-knight-soul-data.lua`, generated by
  `scripts/generate-basic-death-knight-soul-data`.

- `buddy-talents.lua` (617g) — buddies spend their own talent points by
  their shape (e.g. two-thirds Holy, one-third Protection), randomly within
  it, on level-up and login, and re-roll when their owner respecs. The
  decisions live in `lib/buddy-talent-spender.lua` (no server calls, so
  `scripts/test-buddy-talents` runs the same code offline); the class
  trees in `data/buddy-talent-data.lua`, generated by
  `scripts/generate-basic-talent-data`.

- `sargobras.lua` (617b, 617l) — Sargobras the buddy selector: the valley
  ones and the one that wanders beside an owner who is owed a buddy; his
  menu turns a pick (a class or a race) into a buddy written into the
  roster, fills death-knight owners' slots on his own, lights a campfire
  and tells jokes when done, and names the clan's guild. The choice rules
  are in `lib/buddy-choice.lua` (tested by `scripts/test-buddy-choice`);
  races and classes in `data/race-class-data.lua`
  (`scripts/generate-basic-race-class-data`).

- `world-boss-respawn.lua` (155j) — the world bosses come back on its
  countdown, not the server's timer: every 5 seconds each dead boss's
  countdown moves on, held back by "moment tokens" the players in its area
  deposit (2.5 hours with nobody there, never with 100); when due it asks
  the server's code (`src/cpp-basic/basic_rules.cpp`) to bring the boss
  back. The rule is in `lib/world-boss-countdown.lua` (tested by
  `scripts/test-world-boss-countdown`).

- `neuron-spawn.lua` (162) — `NeuronSpawn.at`, one reusable ground-probed
  creature placement, mirroring the sequence `../wow-chat-neuron`'s
  `world.spawn` currently generates inline for every creature it places.
  Not called by neuron yet (only the `basic` profile loads this directory,
  and neuron's active profile is `vanilla`); see the file's own header and
  issue 162's Open Questions.

`lib/` holds plain Lua modules the scripts load with dofile. ALE's scan also
runs them once on their own; each only builds and returns its table.

This directory must exist even while empty: E001 treats a missing
per-profile Lua directory as an error, because a missing directory means
the profile was never set up or `.profile` is misspelled.

Sibling directories:
- `src/lua-vanilla/` — vanilla's starter-kit hook.
- `src/lua-beta/` — the wow-chat design corpus.
- `src/lua-alpha/` — placeholder for alpha (mod-eluna) scripts.
