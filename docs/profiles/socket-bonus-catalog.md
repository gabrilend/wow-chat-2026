# Socket Bonus Catalog

Every item enchantment the game client already has text for, as a
catalog of possible socket bonuses ("option 1": point an item's
socket bonus at one of these and the tooltip is correct with no client
change). Generated by `scripts/generate-socket-bonus-catalog` from the
client's SpellItemEnchantment, GemProperties and Spell files and the
`acore_world` database; re-run it rather than editing this page.

How to read it:

- Rows are grouped by kind, then by wording (texts that differ only in
  their numbers sit together), smallest first. Across different stats
  the sizes are not comparable (10 spell power is not 10 Stamina).
- **Bonus on** = how many items already use it as their socket bonus,
  and their item levels: a guide to what Blizzard thought a bonus of
  that size was worth at that level.
- **Also from** = the gems whose effect it is.
- **Notes**: the spell an aura or on-hit row casts; a required level or
  skill (the server may refuse the bonus to a wearer below it); a meta
  condition (only checked for meta gems).
- Untested as socket bonuses in game; the server applies all these
  kinds through the same enchantment code it uses for sockets.
