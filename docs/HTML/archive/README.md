# Archived pages

Pages kept as they were on a given day, so a design the owner liked stays
openable after its live version moves on. Each opens straight from its file.

- `fish-sandbox-2026-10-28.html`: the fish-school sandbox (issue 617e16), as
  it stood when the owner said: "this pathfinding design is excellent, make
  sure a copy of it is archived. It's not quite what we're looking for, but
  it's delightful." 36 bots flocking clockwise inside monster-spawn fences
  over flat zone squares. Its template: `scripts/templates/archive/`. Its
  successor on the ground (heights, slopes, doodads): issue 617e16c.
