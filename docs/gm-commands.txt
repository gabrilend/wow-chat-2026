================================================================================
  NEURON
================================================================================

wow-chat-neuron (../wow-chat-neuron/, the control plane for a running
AzerothCore world) reaches the world through three channels; its live channel
sends game master commands over the worldserver's SOAP console. Every command
listed here should be able to become a neuron operation: one declaration, from
which neuron draws a command-line subcommand, a tool definition a model can call
(a tool call), and an entry in its catalogue (docs/vocabulary.txt there). Each
line below already holds what a declaration needs: the command's words (its
name), its syntax (its typed parameters), its level (who may pull the lever) and
where it runs.

Where it runs decides the channel. A command marked "anywhere" can be sent over
SOAP as it stands, so it maps straight onto neuron's live channel. One marked
"in game" needs a character in the world (it reads the game master's position,
target or selection), so as a neuron operation it would be carried by the
resident channel (a Lua script in the server that acts for a named character) or
rewritten to take that character as a parameter. A "?" means the code did not
say.

================================================================================
  HOW TO READ THIS
================================================================================

Systems are in capitals, underlined. Inside a system, command families (a
command's first word) are in word order, and inside a family the commands nest
by their words: ".account set gmlevel" sits in "account set", inside "account".
Each command line gives its syntax, then in brackets who may run it and where:

  player     any account          moderator  game master level 1
  gm         game master level 2  admin      game master level 3
  console    the server console only

  anywhere   runs in game and from the server console (and so over SOAP)
  in game    needs a character in the world
  NEW        added by this project

In a syntax, $word and #number are the stock help's own marks for a value to
type; the project's commands use <needed> and [optional], with a|b for a choice.
The help under each command is the server's own (.help shows the same), except
for NEW ones, whose help is config/custom-gm-commands.lua.
