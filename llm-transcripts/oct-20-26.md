**What a new profile touches** (going by how cc-test was added, in the issue
file for the custom client's test server):
- **The profile list script**: which upstream source it builds from, the pinned
  commit, and which modules it loads.
- **The patch lists**: which source patches go on before compiling, and which
  install steps run (the database setup, the link to its Lua folder, the log
  folder).
- **The config patches** that switch on profile name: realm number (cc-test is
  6, so econ would be 7), network ports, folder paths, and database connections.
- **The install and switch scripts**, and the creation of its three databases:
  `acore_world_econ`, `acore_characters_econ`, `acore_playerbots_econ`.
- **A Lua folder** (`src/lua-econ/`), a page in `docs/profiles/`, and a line in
  CLAUDE.md.
- **An issue file**, written before any of this. I'll check whether the old
  "explore profile" issue overlaps first.

I can do all of that. After that you would run the compile and install, since
those builds are yours to run.

**Questions that decide the shape:**

1. **Which world does econ start from?** I see three choices:
