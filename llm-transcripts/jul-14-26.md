Here's the lay of the land. The project isn't one server — it's **four
distinct play-experience profiles** that share most of the same machinery
(source tree, MySQL, scripts) but each present a different ruleset. The active
one is selected by a single file, `.profile`, at the project root (right now it
reads `vanilla`). Every script reads that file to decide which install dir,
source tree, and database namespace to touch.

They fall on **two independent axes**, not a single ladder:

## The promotion pipeline (alpha → beta → release)
These three are the same wow-chat custom design at three different maturities. A
feature is written in **beta**, hardened, and only graduates "up" into
**release** once it's proven not to crash or regress. **alpha** sits outside the
pipeline as a historical snapshot.

**Beta** — *active-development tier, fully built.* Everything the project can
do, all custom source patches applied (currently ~23 of them), the full
experimental Lua corpus in `src/lua-beta/`. The "empty world, monsters
ambush-spawn around the player" design, custom classes, per-level talent points,
all ALE Lua hooks. This is the canonical "what does it look like with everything
on" build. If something's broken here but fine on release, that difference *is*
the in-flight work.

**Release** — *proven-working subset, built.* Intended as the public-play
production server. Identical design layer to beta but only the parts that
graduated. It's guaranteed to be a strict subset of beta — that's what makes
it the stable tier. Shares databases and ports with beta, so the two can't run
at the same time.

**Alpha** — *mostly planned / a relic.* A frozen time-capsule of the
*previous* project (wow-chat-1): a pinned-old AzerothCore, the older mod-eluna
scripting engine instead of ALE, no playerbots, the read-only `libs/wow-chat-1/`
scripts. Intended to be dusted off ~one week a year for nostalgia. It's the
**least built** of the four — the source commit pin is still a TODO (issue
136), its isolated MySQL instance on port 3308 isn't stood up yet (issue 147),
and `src/lua-alpha/` is an empty placeholder.

## The vanilla branch (parallel, not on the pipeline)
**Vanilla** — *the current default, most self-contained.* Deliberately **not**
the wow-chat design. It's near-stock WotLK 3.3.5a plus AI playerbots and a light
ruleset: start at level 20, cap at 40, fixed faction starting zones
(Alliance→Darkshire, Horde→Tarren Mill), no flight paths, a full
white-quality level-20 starter kit per class, all trainer abilities through 20
pre-learned, slower movement + heavier fall damage, Death Knight disabled. Its
own minimal Lua corpus (`src/lua-vanilla/`, currently just the auto-equip hook)
and its own suffixed databases (`acore_*_vanilla`). It shares infrastructure
with beta/release but runs its own ruleset — and can run concurrently with a
release server since it's on different ports.

The canonical rules for all of this (including the protocol for ever adding a
